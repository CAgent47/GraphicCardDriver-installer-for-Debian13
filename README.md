# How To Use 🤔

1. Download 📦
```bash
git clone https://github.com/CAgent47/GraphicCardDriver-installer-for-Debian13.git
```

2. **Extract File and Goto Script Folder 📂**
3.**Run ▶️**
```bash
# 1
chmod +x installer.sh

# 2 RUN
./installer.sh
```
